## On the work done

The `_ts_equal_within` bug was real — calling `.astimezone(UTC)` on a naive datetime in Python silently interprets it as local time, which would produce wrong drift comparisons on non-UTC machines. The fix (normalize naive → UTC via `replace(tzinfo=UTC)`) is correct and consistent across both modules.

The BC-194 test file was the main deliverable. The InMemoryRegista silently skipping events when `key_set is None` caught me — my first test run had 8 failures. This is documented in AGENTS.md now, but it's a genuine footgun: the backend diverges from Postgres behavior in a way that only manifests when asserting on event counts. The `test_in_memory_conformance.py` fixture deliberately omits `hmac_key_path`, which means its heartbeat test only checks TTL extension, never event emission. Not wrong, but not obvious.

Migration renumbering was clean — just file renames plus one comment in `_migrations.py`. No production data makes this safe.
