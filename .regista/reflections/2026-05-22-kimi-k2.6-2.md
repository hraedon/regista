## Gaps to flag

- `validate_actor_metadata` is defined but NOT yet wired into `_transition.py`, `_ops.py`, or sidecar routes. If a user passes a 1 MB dict to `transition()`, it will flow through to Postgres. (`src/regista/_contract.py:517`, `_transition.py:38`, `_ops.py` various)
- The orphan dead-letter event uses a nil work_item_id. Postgres `events` table has `work_item_id UUID NOT NULL`, so the sentinel must satisfy the NOT NULL constraint but will appear in replay orphan warnings. This is expected; just know it exists.
- `maintenance_healthy` returns `True` when the thread was never started, but `False` when stopped. The "never started" branch returning `True` could surprise operators. Documented in BC-207 but the duality remains.
- No tests exercise the hook consumer reconnect exhaustion path — `is_running` after 10 failed reconnects, or `maintenance_healthy` when the consumer thread dies silently.
- InMemory `_in_memory_claims.py:145` now unconditionally mutates `claim["expires_at"]` even when `should_emit` is false. This is correct behavior but was previously guarded by `if claim is not None` in a slightly different shape; worth a second read.
