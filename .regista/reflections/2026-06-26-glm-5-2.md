## On the project

The reconciliation was overdue and the state confirmed the Session 71
reflection's read: there was real, reviewed, green work (Plan 021) sitting
unpushed, and a `pyproject.toml` pinned at `0.4.0` while a large batch of
additive features had accumulated unreleased. That's the pre-1.0 library's
main process risk — features land and get reviewed, but the release/tag
discipline lags, so consumers can't pin against what actually exists. Cutting
`v0.5.0` was the single highest-leverage act this session; dossier now has a
real version to target that includes the `ValidatorContext.on_behalf_of` field
it needs.

The replay internals are well-factored for this kind of scoping: per-item
verification (`_replay_work_item`) was already cleanly separable from the
global invariants (global chain, chain head, TSP batches), so adding a
`work_item_id` filter was mostly threading and skipping the right blocks. The
honest design call — scoped replay *cannot* verify global invariants and must
say so — landed cleanly and is documented in the docstring and the one-warning
contract.

## On the work done

corruption-masking fix, and the release cut. The 1208-test suite is green and

The adversarial review process was the weak point this session. The glm

cross-lineage property was compromised by the glm reviewer's failure. Worth
noting for next session — if glm returns empty again, the review is degraded,
not clean.

## On what remains

1. **dossier can now move** — pin regista `0.5.0`, consume `replay(work_item_id=…)`
   for the per-issue integrity badge (its WI-003), and the `ValidatorContext.on_behalf_of`
   field for the adversarial-review validator (its WI-004). That's the
   dossier-go-live unblock.
2. **BC-310 (high)** — replay runs under READ COMMITTED, so scoped *and* full
   replay can report false drift under concurrent writes. Right fix is
   `REPEATABLE READ` for the replay transaction (or `FOR UPDATE` on the single
   row for scoped). This is the most consequential open correctness item; it
   predates this session but is now the obvious next structural investment.
3. **BC-308 (medium)** — signing-envelope version consolidation. Still the
   highest-value structural cleanup before mixed human+agent operation; latent
   for the all-human dossier MVP.

Nice-to-have: a comprehensive CHANGELOG backfill of all work since `0.4.0`
(there are ~190 resolved breadcrumbs; only a representative subset is in the

  documented anywhere a consumer would see.
