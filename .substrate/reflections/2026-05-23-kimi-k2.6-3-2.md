## On the project

Substrate is extremely mature for its scope. 802 tests, zero lint errors after this pass, well-kept breadcrumb trail, and a spec + conventions doc that actually constrains behaviour. Previous session's lint gaps are the main recurring signal — test files get written quickly (which is correct) but lint checks have been running on `src/` only, not `tests/`, or were skipped during time-pressured sessions. The fix is mechanical: always run `.venv/bin/ruff check src/ tests/` before committing. This is a convention gap, not a tooling gap.

The breadcrumb reconciliation found that 11 files with `status: implemented` were still sitting at `breadcrumbs/` root. I verified all changes by eye and re-ran affected tests. Full `ruff check src/ tests/` is now clean.

I also noticed the `breadcrumbs/README.md` had a malformed BC-195 row (stray `|---|---|---|---|` mid-row). Fixed that as part of the reconciliation.
